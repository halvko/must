Must Wasm Playground

Run a WebAssembly module compiled by must-lsp, entirely in this page — no server, no install.

How to compile: 
must-lsp compile examples/display.must -o display.wasm
Drop a .wasm file here, or

must.print output




Result


Load a module to begin.




  Limits. This backend has no heap and no raw pointers yet —
  programs using them (examples/heap.must, examples/pointers.must)
  are refused at compile time, so there is nothing for this page to run for
  those. The module's only import is must.print, not WASI, so a
  general-purpose WASI runtime (wasmtime, wasmer, …) will not run
  these modules as-is — a --wasi shim is future work. This page
  supplies exactly the one import the module needs and nothing else.
